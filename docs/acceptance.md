# 部署验收

以下项目必须在目标美国服务器执行；未执行不标记通过。

- [ ] 核对机房位置、剩余空间、内存和月流量；确认不会影响现有服务。
- [ ] DATA_ROOT 在仓库之外，配置、媒体、缓存和备份均在境外服务器。
- [ ] 首次启动的 8096 仅监听 127.0.0.1，SSH 隧道内完成账号初始化。
- [ ] HTTPS 域名正常，未登录无法播放受保护媒体，媒体端口没有直接暴露公网。
- [ ] 视频和音频都可播放，拖动进度正常；记录实际使用版本和客户端。
- [ ] 创建合集、修改名称和封面、加入及移除条目，原文件保持完整。
- [ ] 创建播放列表并调整顺序，连续播放符合顺序。
- [ ] 系列课程显示正确集号，能定位已看与未看内容。
- [ ] 视频播放超过续播阈值后停止，刷新、重新登录能从停止位置继续。
- [ ] 手机和电脑登录同一账号能接续，不同账号进度互不影响。
- [ ] 长音频按有声书分类后，在实际格式和客户端上测试退出、重启及跨设备续听；不通过则单独调整方案。
- [ ] 重建容器后账号、合集、播放进度仍在。
- [ ] 配置备份可生成并在隔离实例完成恢复验证；媒体另行备份。
- [ ] Git 跟踪文件中无媒体、.env、账号数据库、备份和访问凭据。
